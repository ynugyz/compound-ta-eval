# 03. 独立调研与立项可行性评估工作流（SOP）

> **用途**：本工作流既用于内部调研与立项评估，也供外部独立 AI（如未接入本项目历史上下文的 Claude）完整复现。请**严格遵循隔离与查证纪律**，不要迎合发起人设想。

---

## 一、盲审隔离纪律（严禁先看答案）

1. **阶段 1–4（完全盲审）**：**只读** `01-blind-input-pack/` 下的文件（`01_PROBLEM_AND_VISION.md`、`02_EXISTING_EMPIRICAL_EVIDENCE.md` 与本文档），**严禁提前读取 `02-vera-proposal/` 目录中的任何文件**。
2. **阶段 5（交叉对照）**：仅当你自己完成全部联网检索、竞品核验、风险拆解并写下独立结论后，才允许打开 `02-vera-proposal/`，逐项对照差异并给出严苛的红队修正意见。
3. **证据铁律**：
   - 严禁凭过时记忆断言竞品“没有某功能”——所有竞品能力、定价、近期更新与开源现状**必须通过当前联网检索或官方文档/GitHub 实查核验**，并附可追溯 URL；
   - 明确区分 **【已核验事实】** 与 **【尚未验证的推断/假设】**；
   - 严禁“AI 机械拼接式夸奖”——若“大而全集成平台”在 1–3 人团队下不可行，必须直言不讳指出哪些模块该砍、该延后或该换切口。

## 二、标准 4 步调研与评估流程

### Step 1：2026 竞品与生态全景实查（防重复造轮子）
请联网检索以下 4 类代表性产品的**最新真实功能、免费/付费边界与用户核心差评**：
1. **源文档驱动型 AI 学习工具**：Google NotebookLM（含 Study Guide / Quiz / Audio Overview / Mind Map 等最新特性）、Open DeepTutor、YouLearn / Turbolearn AI、Mindgrasp、PDF.ai / ChatPDF；
2. **知识库 + 间隔复习复利工具**：RemNote（含 PDF 批注 + 闪卡 + FSRS）、Anki（FSRS 算法生态）、Heptabase、Logseq / Obsidian + AI 插件生态、Recall.ai；
3. **通用大模型的学习模式与本土生态**：ChatGPT Study Mode / Canvas、Claude Artifacts / Projects、Perplexity、以及中国高校学生高频使用的 Kimi、豆包、腾讯 ima、Get 笔记、夸克学习等；
4. **自适应测验与题库类产品**：Knowt、Quizlet（Q-Chat / Learn）、Khanmigo / Duolingo Max 的微交互设计。

**输出要求**：一张结构化对比矩阵，明确回答——**发起人构想的哪一部分其实已经被竞品免费做烂了？哪一部分是真正尚未被解决的真实缺口？**

### Step 2：真实用户痛点与 Day-7 留存/弃用归因
检索真实学习者社区反馈（如 Reddit `r/studying`、`r/Anki`、`r/ObsidianMD`、`r/notebooklm`、GitHub Issues、知乎/小红书/B 站大学生关于 AI 学习工具的真实吐槽），重点核查：
1. 为什么学生“刚用 AI 学习工具觉得很爽，但 7 天后弃用或回归手写/传统刷题”？
2. “集成式全能学习平台”历史上有哪些失败教训（如冷启动负担过重、导入摩擦、自动出题质量烂、界面臃肿）？
3. “变密度大纲 + 零打字微诊断 + 卡壳回原页局部问答 + 个人复利知识库”这一组合，在真实学习流中最容易在哪一步断裂？

### Step 3：技术、成本、内容质量与竞赛可行性体检
从 4 个硬维度做压力测试：
1. **内容与题库质量瓶颈**：任意 PDF/PPT（含扫描件、数学公式、图表）上传后，自动生成“高区分度微诊断题 + 零幻觉原文回指”的真实失误率有多高？怎么防止烂题毁掉整个产品体验？
2. **单位成本与延迟**：针对高校学生免费/低付费现实，单章解析 + 双层索引 + 按需局部问答 + 长期复习的 Token 成本账怎么算？快慢路径分层能否把单用户月成本压到可承受区间？
3. **1–3 人学生团队的范围失控风险（Scope Creep Audit）**：面对“多源输入 + 笔记知识库 + 题库做题 + 错题复习 + 微打卡 + 局部问答 + 个人复利”这一宏大愿景，**哪些必须进 V1（MVP），哪些必须砍进 V2/V3，哪些根本不该自己造轮子（应靠导入/导出对接现有生态如 Obsidian/Anki）**？
4. **竞赛适配度审查**：分别评估该项目对 **挑战杯（大挑 vs 小挑）**、**高校 AI 教育应用赛（如字节系等校园 AI 赛）**、**大创** 的核心得分点、硬伤（例如：缺少大规模真实教学对照实验数据、评委质疑“套壳大模型”、与大厂原生功能撞车）以及破局所需的最少硬证据。

### Step 4：独立裁决与 8 维打分卡
请给出明确裁决：**`GO` / `CONDITIONAL GO（有条件立项）` / `PIVOT（换切口）` / `KILL（不建议立项）`**，并按以下 8 维输出（每维 1–5 分 + 1 句硬理由）：
1. 真实痛点强度
2. 相对 2026 竞品的不可替代性
3. 个人复利闭环的留存可行性
4. 自动出题与证据溯源的技术可行性
5. 1–3 人团队的工程落地可行性（防范围失控）
6. 成本与商业/合规可持续性
7. 高校竞赛竞争力（挑战杯/应用赛/大创）
8. 现阶段实验验证路径清晰度

最后必须列出：
- **Top 3 致命风险（最可能导致项目失败或答辩被秒杀的原因）**
- **推荐的 V1 最小闭环边界（做什么 / 明确不做什么）**
- **进入下一阶段前必须先拿到的 3 个量化门禁指标**
